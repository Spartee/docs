[Arcade](https://arcade.dev) is the leading MCP runtime that enables AI agents to take real-world actions securely at scale. It handles OAuth automatically, manages user tokens securely, and provides access to 1000s of tools across Gmail, Slack, GitHub, Google Sheets, Notion, Stripe, and many more services. As a native MCP server, Arcade works seamlessly with any MCP-compatible client including LangChain, LangGraph, Claude Desktop, Cursor, and VS Code.

## Instantiation

Initialize the Arcade client and fetch tools from specific toolkits. Each toolkit represents a service (e.g., Gmail, Slack) with multiple tools (actions you can perform).

```typescript Initialize Arcade
import Arcade from '@arcadeai/arcadejs';

// Initialize Arcade client
const arcade = new Arcade({
    apiKey: process.env.ARCADE_API_KEY,
});

// Get tools from specific toolkits
const tools = await arcade.tools.list({ toolkit: 'Gmail', limit: 30 });

console.log(`Loaded ${tools.items.length} tools from Gmail toolkit`);
```

## Converting Arcade tools to LangChain

Arcade tools need to be converted to LangChain-compatible tools using Zod schemas. Here's a complete conversion utility:

```typescript Type mapping and schema conversion
import { z } from 'zod';
import { tool } from '@langchain/core/tools';
import Arcade from '@arcadeai/arcadejs';

const TYPE_MAPPING: Record<string, z.ZodType> = {
    string: z.string(),
    number: z.number(),
    integer: z.number().int(),
    boolean: z.boolean(),
    array: z.array(z.any()),
    json: z.record(z.any()),
};

function getZodType(valType: string): z.ZodType {
    const zodType = TYPE_MAPPING[valType];
    if (!zodType) {
        throw new Error(`Invalid value type: ${valType}`);
    }
    return zodType;
}

function arcadeSchemaToZod(toolDef: any): z.ZodObject<any> {
    const shape: Record<string, z.ZodType> = {};

    for (const param of toolDef.input.parameters || []) {
        let paramType = getZodType(param.value_schema.val_type);

        if (param.value_schema.val_type === 'array' && param.value_schema.inner_val_type) {
            const innerType = getZodType(param.value_schema.inner_val_type);
            paramType = z.array(innerType);
        }

        if (param.description) {
            paramType = paramType.describe(param.description);
        }

        shape[param.name] = param.required ? paramType : paramType.optional();
    }

    return z.object(shape);
}
```

```typescript Convert Arcade tools to LangChain
async function arcadeToLangchain(
    arcadeClient: Arcade,
    arcadeTool: any,
    userId: string
) {
    const schema = arcadeSchemaToZod(arcadeTool);

    return tool(
        async (input: Record<string, any>) => {
            // Check authorization status
            const authResponse = await arcadeClient.tools.authorize({
                tool_name: arcadeTool.qualified_name,
                user_id: userId
            });

            if (authResponse.status !== 'completed') {
                return {
                    authorization_required: true,
                    auth_url: authResponse.url,
                    auth_id: authResponse.id
                };
            }

            // Execute the tool
            const response = await arcadeClient.tools.execute({
                tool_name: arcadeTool.qualified_name,
                input,
                user_id: userId,
            });

            if (response.output?.error || response.success === false) {
                return { error: response.output?.error?.message ?? 'Tool execution failed' };
            }
            if (response.output) {
                return response.output.value;
            }
            return { error: 'Tool execution returned no output' };
        },
        {
            name: arcadeTool.qualified_name.replace(/\./g, '_'),
            description: arcadeTool.description,
            schema,
        }
    );
}
```

## Get tools from Arcade

Retrieve tools from specific toolkits or by name:

```typescript Get tools helper
async function getArcadeTools(options: {
    arcadeClient?: Arcade;
    toolkits?: string[];
    tools?: string[];
    userId: string;
    toolLimit?: number;
}) {
    const { toolkits, tools, userId, toolLimit = 30 } = options;
    const arcadeClient = options.arcadeClient || new Arcade();

    if (!tools && !toolkits) {
        throw new Error('Provide either tools or toolkits');
    }

    const toolDefinitions: Map<string, any> = new Map();

    // Get specific tools by name
    if (tools) {
        const responses = await Promise.all(
            tools.map(toolName => arcadeClient.tools.get(toolName))
        );
        for (const response of responses) {
            toolDefinitions.set(response.fully_qualified_name, response);
        }
    }

    // Get all tools from toolkits
    if (toolkits) {
        const responses = await Promise.all(
            toolkits.map(toolkit =>
                arcadeClient.tools.list({ toolkit, limit: toolLimit })
            )
        );
        for (const response of responses) {
            for (const tool of response.items) {
                toolDefinitions.set(tool.fully_qualified_name, tool);
            }
        }
    }

    // Convert to LangChain tools
    const langchainTools = await Promise.all(
        Array.from(toolDefinitions.values()).map(toolDef =>
            arcadeToLangchain(arcadeClient, toolDef, userId)
        )
    );

    return langchainTools;
}
```

## Use within an agent

Here's a complete example using Arcade tools with a LangGraph agent:

```typescript Agent with Arcade tools
import { ChatOpenAI } from '@langchain/openai';
import { createReactAgent } from '@langchain/langgraph/prebuilt';
import { MemorySaver } from '@langchain/langgraph';
import Arcade from '@arcadeai/arcadejs';

// Initialize Arcade
const arcade = new Arcade({
    apiKey: process.env.ARCADE_API_KEY,
});

// Get Gmail tools
const tools = await getArcadeTools({
    arcadeClient: arcade,
    tools: ['Gmail_ListEmails', 'Gmail_SendEmail'],
    userId: 'user@example.com'
});

// Create model
const model = new ChatOpenAI({
    model: 'gpt-4o',
});

// Create agent with memory
const memory = new MemorySaver();
const agent = createReactAgent({
    llm: model,
    tools,
    checkpointSaver: memory
});

// Run the agent
const result = await agent.invoke(
    {
        messages: [
            { role: 'user', content: 'List my latest 3 emails' }
        ]
    },
    {
        configurable: {
            thread_id: 'email_thread'
        }
    }
);

console.log(result.messages[result.messages.length - 1].content);
```

### Using with LangGraph StateGraph

Here's a more advanced example using a StateGraph:

```typescript
import { ChatOpenAI } from '@langchain/openai';
import { HumanMessage, AIMessage } from '@langchain/core/messages';
import { ToolNode } from '@langchain/langgraph/prebuilt';
import { StateGraph, MessagesAnnotation } from '@langchain/langgraph';
import Arcade from '@arcadeai/arcadejs';

// Initialize Arcade
const arcade = new Arcade({
    apiKey: process.env.ARCADE_API_KEY,
});

// Fetch the tools
const tools = await getArcadeTools({
    arcadeClient: arcade,
    toolkits: ['Gmail'],
    userId: 'user@example.com'
});

// Define the tools for the agent to use
const toolNode = new ToolNode(tools);

// Create a model and give it access to the tools
const model = new ChatOpenAI({
    model: 'gpt-4o',
}).bindTools(tools);

// Define the function that determines whether to continue or not
function shouldContinue({ messages }: typeof MessagesAnnotation.State) {
    const lastMessage = messages[messages.length - 1] as AIMessage;

    if (lastMessage.tool_calls?.length) {
        return 'tools';
    }
    return '__end__';
}

// Define the function that calls the model
async function callModel(state: typeof MessagesAnnotation.State) {
    const response = await model.invoke(state.messages);
    return { messages: [response] };
}

// Define a new graph
const workflow = new StateGraph(MessagesAnnotation)
    .addNode('agent', callModel)
    .addEdge('__start__', 'agent')
    .addNode('tools', toolNode)
    .addEdge('tools', 'agent')
    .addConditionalEdges('agent', shouldContinue);

// Compile the graph
const app = workflow.compile();

// Use the agent
const finalState = await app.invoke({
    messages: [new HumanMessage('Summarize my latest email')]
});

console.log(finalState.messages[finalState.messages.length - 1].content);
```

## Authentication handling

Arcade manages OAuth flows for you. When a tool requires authorization, you'll receive an auth URL:

```typescript
import Arcade from '@arcadeai/arcadejs';

const arcade = new Arcade();
const userId = 'user@example.com';

// Start authorization for a provider
const authResponse = await arcade.auth.start(userId, 'google', {
    scopes: ['https://www.googleapis.com/auth/gmail.readonly'],
});

if (authResponse.status !== 'completed') {
    console.log('Please authorize the application:');
    console.log(authResponse.url);
}

// Wait for user to complete authorization
const completedAuth = await arcade.auth.waitForCompletion(authResponse);
console.log('Authorization completed!');
```

## Using with LangChain tools directly

You can use Arcade to get OAuth tokens and use them with existing LangChain tool integrations:

```typescript
import Arcade from '@arcadeai/arcadejs';
import {
    GmailCreateDraft,
    GmailGetMessage,
    GmailGetThread,
    GmailSearch,
    GmailSendMessage,
} from '@langchain/community/tools/gmail';

// Get token from Arcade
const arcade = new Arcade();
const authResponse = await arcade.auth.start('user@example.com', 'google', {
    scopes: ['https://www.googleapis.com/auth/gmail.readonly'],
});

if (authResponse.status !== 'completed') {
    console.log(`Authorize at: ${authResponse.url}`);
}

const completedAuth = await arcade.auth.waitForCompletion(authResponse);

// Use token with LangChain Gmail tools
const gmailParams = {
    credentials: {
        accessToken: completedAuth.context.token,
    },
};

const tools = [
    new GmailCreateDraft(gmailParams),
    new GmailGetMessage(gmailParams),
    new GmailGetThread(gmailParams),
    new GmailSearch(gmailParams),
    new GmailSendMessage(gmailParams),
];
```

## Multi-user scenarios

Arcade handles per-user authentication automatically:

```typescript
// Each user has their own authenticated sessions
const toolsUser1 = await getArcadeTools({
    toolkits: ['Gmail'],
    userId: 'user_1@example.com'
});

const toolsUser2 = await getArcadeTools({
    toolkits: ['Gmail'],
    userId: 'user_2@example.com'
});

// Tools will use the respective user's credentials
const agent1 = createReactAgent({ llm: model, tools: toolsUser1 });
const agent2 = createReactAgent({ llm: model, tools: toolsUser2 });
```

## Advanced features

### Direct tool execution

Execute tools directly without an agent:

```typescript
import Arcade from '@arcadeai/arcadejs';

const arcade = new Arcade({
    apiKey: process.env.ARCADE_API_KEY,
});

const result = await arcade.tools.execute({
    tool_name: 'Gmail.ListEmails',
    input: { n_emails: 10 },
    user_id: 'user@example.com',
});

console.log(result.output?.value);
```

### Error handling

Implement robust error handling:

```typescript
const result = await arcade.tools.execute({
    tool_name: 'Gmail.ListEmails',
    input: { n_emails: 10 },
    user_id: 'user@example.com',
}).catch(async (err) => {
    if (err instanceof Arcade.APIError) {
        console.log('Status:', err.status);
        console.log('Error:', err.name);
        console.log('Headers:', err.headers);
    } else {
        throw err;
    }
});
```
